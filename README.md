# Writing

Product name: **Writing**.

Markdown is the single source of truth for book, learning, atlas, and reference modes.

## Stack

- Next.js App Router + TypeScript (strict) + React + Tailwind CSS
- pnpm, ESLint, Prettier, Vitest, React Testing Library, Playwright, Zod

## Scripts

```bash
pnpm install
pnpm dev
pnpm lint
pnpm type-check
pnpm test
pnpm build
```

## Source content

Authoritative copies live in `content/source/`. Imports remain in `imports/`.
